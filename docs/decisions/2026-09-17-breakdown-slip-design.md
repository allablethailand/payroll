# สลิปที่แก้ได้ — R1 design: ตาราง line-override + สรุปท้ายสลิป (2026-09-17)

ตาราง line-override เป็น shared (หลัง D3 เหลือ mount เดียวคือ `#runDetailBreakdownModal`) — ทุกข้อด้านล่างมีผลทุกที่ที่เรียก

**คอลัมน์ "ค่าที่ระบบคำนวณ" มาจาก 2 ที่ ไม่ใช่ field เดียว** — ไม่มี override: ค่าที่โชว์อยู่**คือ**ค่าที่ระบบคำนวณ · มี override:
`original_value` ของประวัติแถวนั้น · override ที่เก่ากว่าตารางประวัติไม่มีทั้งคู่ → "-" + title (วัดใน dev DB: 0 แถว) ·
หัว dropdown เลิกกดได้ เพราะการกลับไปใช้ค่าระบบเป็นปุ่มกลมในแถว (confirm + ยิงทางเดิมเป๊ะ) · **ปุ่ม/ตัวเลข/การกระทำ แยกคอลัมน์กัน**:
action เป็นคอลัมน์ไม่มีหัว กว้างพอ 2 ปุ่มพอดี เพื่อให้คอลัมน์เงินจบที่ x เดียวเสมอ และไม่ขยับตอนเปิด inline edit (editor อยู่ใน 2 เซลล์เดิม)

**4 บั๊กจริงที่เจอตอนวัด ไม่ใช่ของใหม่จากรอบนี้**: (1) `.money-*` ประกาศเป็น `.num.money-*` แต่ span ในตารางไม่เคยมี `.num`
→ **ตัวเลขในตารางนี้ไม่เคยมีสีเลย** · (2) `data-bs-strategy` ไม่ใช่ option ของ Bootstrap Dropdown (เป็นของ Tooltip/Popover)
ต้องส่ง `popperConfig` เข้า instance · (3) z-index ของ modal ซ้อนถูกตั้งใน `shown.bs.modal` = หลัง fade-in จบ modal จึงเล่น
แอนิเมชันทั้งตัวที่ระดับล่างแล้วค่อยกระโดดขึ้นหน้า — ย้ายเป็น class ใน `show.bs.modal` + กฎ CSS, backdrop ใช้ selector
`.modal-backdrop ~ .modal-backdrop` (ตรงตอนถูก insert ไม่ต้องรอ callback) · (4) `width: 1%` ของคอลัมน์ประวัติเป็นทริกของ
ตาราง auto พอเปลี่ยนเป็น `table-layout: fixed` มันยุบจริงตามตัวอักษร · (5) `.modal-fullscreen` มีทางออก
`max-height: 100%` ให้ `.modal-body` มานานแล้ว แต่ **`.modal-fullscreen-sm-down` ไม่เคยมี** — บนมือถือ dialog สูงเต็ม 932
แต่ body ยังโดน cap ที่ `100vh − 200px` = 732 footer เลยลอยอยู่เหนือขอบล่าง **97px** (วัดที่ 430×932 ก่อนแก้)
