# 2026-09-15 — payslip-view inset + ช่องค้นหาใน column-filter popup

## 1. payslip-view: ข้อความในแถบรวมชิดขอบแถบ

**อาการที่รายงาน**: แถบเทา "รวมรายได้ / รวมรายการหัก" ข้อความชิดขอบแถบ ขณะที่แถบ "ยอดจ่ายสุทธิ" ดูมีระยะห่างปกติ

**ค่าที่วัดได้จริงก่อนแก้** (computed `padding-left`, modal Calculation Breakdown บนหน้า Payroll Detail):

| element | padding-left | x ของข้อความ |
|---|---|---|
| `.payslip-col-title` (หัวคอลัมน์) | 0px | 312 |
| `.payslip-row td` (แถวรายการ) | 0px | 312 |
| `.payslip-col-total` (แถบรวมต่อคอลัมน์) | 0px | 312 |
| `.payslip-summary-row-net` (แถบสุทธิ) | 12px | 324 |

**ต้นเหตุ**: งานเฟส C เคยสั่งให้หัวคอลัมน์/`.payslip-row`/`.payslip-col-total` ใช้ padding แนวนอนเดียวกับแถบสุทธิ
แต่ **rule นั้นไม่เคยมีอยู่ใน `style.css` เลย และไม่มีอะไร override** — ของเดิมเขียน `padding: var(--sp-3) 0
var(--sp-2)` (แนวนอน = 0) ไว้โดยตั้งใจ พร้อม comment อธิบายเหตุผลกำกับ (กัน 2 แถบซ้าย-ขวา bleed เข้าหากันใน
ช่อง `--sp-4` ระหว่างคอลัมน์) — คือคำสั่งเฟส C ถูกทับด้วย follow-up รอบเดียวกันวันนั้น ไม่ได้ถูก override ทาง CSS

**สิ่งที่แก้**: `--payslip-inset` (= `--sp-3`) ประกาศบน `.payslip-view` แล้วใช้กับทั้ง 4 จุด — เหตุผลที่ใช้ตัวแปร
ไม่ใช่ค่าซ้ำ 4 ที่: ประเด็นทั้งหมดของการแก้นี้คือ "4 จุดต้องไม่หลุดจากกันอีก" — และคงข้อจำกัดเดิมไว้ (แถบเต็ม
ความกว้างคอลัมน์ inset อยู่ที่เนื้อหาเท่านั้น) เพื่อไม่ให้ข้อกังวลเรื่อง bleed กลับมา

**หลังแก้ (วัดยืนยัน light + dark)**: ทั้ง 4 จุด padding ซ้าย/ขวา = 12px และข้อความเริ่มที่ x = 324 เท่ากันหมด

## 2. column-filter popup: ไอคอนแว่นทับ placeholder

**ค่าที่วัดได้จริงก่อนแก้**: ไอคอนอยู่ที่ `left: 9px` กว้างจนจบที่ x=23 แต่ `input` มี `padding-left: 1.75rem`
→ ตัวอักษรตัวแรกเริ่มที่ x=22 คือ **ซ้อนกัน −1px** (ไม่ใช่แค่ดูแน่น) และไอคอนมี `pointer-events: auto`
→ คลิกที่ไอคอนแล้ว input ไม่ focus

**สิ่งที่แก้**: ให้ตำแหน่งไอคอนกับจุดเริ่มข้อความมาจาก spacing scale เดียวกัน (ไอคอน `--sp-2`, ข้อความ `--sp-6`)
→ เหลือช่องว่างจริง 10px + `pointer-events: none` — พร้อมเปลี่ยนค่า untokenized ที่ปนอยู่ในบล็อกเดียวกัน
(`1.75rem`/`1.0417rem`/`0.9167rem`/`6px`/`.5rem`) เป็น token ตาม §1

**ทำไมแก้ CSS จุดเดียวถึงพอ**: `ensurePanel()` (`public/js/table-column-filter.js`) สร้าง panel เดียวครั้งเดียว
แล้ว reuse กับทุกคอลัมน์/ทุกตาราง — ทั้งแอปมี 55 call site (ทั้งผ่าน `initSharedDataTable({columnFilters})`
และเรียก `initExcelColumnFilters()` ตรงๆ) ทุกจุดใช้ panel ตัวเดียวกันนี้

**ทดสอบจริง 2 หน้า** (light + dark): Payroll Detail (ผ่าน `initSharedDataTable`) และ Employee List (เรียก
`initExcelColumnFilters()` ตรงๆ, 13 ปุ่ม filter) — ได้ผลตรงกัน: padding-left 32px, ช่องว่างไอคอน→ข้อความ 10px,
คลิกที่ไอคอนแล้ว focus เข้าช่องค้นหาจริง

**หมายเหตุ**: ช่องค้นหา toolbar หลักของ DataTable (`.dt-search input`) เป็นคนละโครง (Bootstrap `form-control-sm`,
font 10.5px, ไม่มีไอคอน) จึงไม่ยกค่าของมันมาทั้งชุด — เอาเฉพาะหลักการ "ตำแหน่งไอคอนกับจุดเริ่มข้อความต้องมาจาก
scale เดียวกัน"
