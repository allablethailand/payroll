# slip2-a — ตารางบรรทัดในสลิปเหลือ 3 คอลัมน์, ปุ่มของแถวย้ายเข้าเซลล์รายการ (2026-09-22)
rules.md §0.1/§0.3/§5/§6/§7/§9 · ต่อจาก [tiny-4b-fix1 v2](2026-09-19-4b-fix1-totals-block.md) และ [H-ui](2026-09-19-h-ui-history-table.md)

**ตัวเลขของแถวกับยอดรวมไม่เคยอยู่แนวเดียวกัน** — วัดก่อนแก้ที่ 1400: ขอบขวาจำนวนเงินของทุกแถว = 900, ตัวเลขใน `.lo-totals` = 1076 ห่างกัน **176px** เพราะมีคอลัมน์ปุ่ม (96) + ประวัติ (86) + padding คั่นอยู่ · แก้ด้วยการทำให้คอลัมน์เงินเป็น `:last-child` แล้วมันได้ `--payslip-inset` ตัวเดียวกับที่บล็อกสรุปใช้ **โดยไม่ต้องเขียนเลขที่ไหนเลย** — วัดหลังแก้: 1076 = 1076 ทั้ง 2 โหมด ทุก cell

**430 เลิก scroll แนวนอน** — ตาราง 5 คอลัมน์ `min-width: 490` ในจอกว้าง 394 (วัดจริง: scrollWidth 530) ผู้ใช้ต้องลากถึงจะเห็นตัวเลข · 3 คอลัมน์ = 78 + 140 + 130 = **348 ≤ 394** → scrollWidth = clientWidth = 394

**ปุ่มอยู่ในเซลล์รายการได้ แต่ตัวนับต้องอยู่ซ้ายของปุ่ม** — ตอนแรกเรียง `[ดินสอ][ช่อง 2][ตัวนับ]` ตามที่ตกลง แล้ววัดได้ว่าดินสอขยับ 39px ระหว่างแถวที่มีประวัติกับแถวที่ไม่มี (บล็อก 107.2 vs 68) เพราะตัวนับเป็น**ข้อความ**ที่ความกว้างไม่มีใครคุม · บล็อกชิดขวา ⇒ อะไรที่อยู่ขวาสุดมี x คงที่ จึงสลับเป็น `[ตัวนับ][ดินสอ][ช่อง 2]` — ดินสอทุกแถว x = 884 เท่ากันหมด (รวมรอบ 10 แถวของ EM009) ตัวนับโตไปทางซ้ายโดยไม่ดันอะไร · **ความกว้างบล็อกไม่คงที่และต้องไม่ assert ว่าคงที่ — ขอบขวาต่างหากที่คงที่**

**ช่อง 2 ตายตัว 1 ช่อง ไม่มีแถวไหนต้องการ 2 อย่าง** — ถังขยะ (manual) | คืนค่าระบบ (`lineOverrideLineIsRestorableRd()`) | ว่างแต่จองที่ 32px · แถว manual ไม่มีค่าระบบให้คืนโดยนิยาม จึงไม่มีทางชนกัน

**คืนค่าระบบต่อแถว = ทางเข้าที่สอง ไม่ใช่ write ใหม่** — เดินผ่าน `runRestoreAllComputedRd([$row], resetExemption)` ตัวเดียวกับ [คืนค่าระบบทั้งหมด] ซึ่งเป็นที่เดียวที่รู้ว่าแถว tri-state ต้องยิง 2 request เรียงกัน · วัดจริง: confirm 1 ครั้ง → `line-override.remove` 1 ครั้ง (ยกเลิก = 0), แถว tri-state → `save-employee-exemption`

**ปุ่มปิดแผงประวัติ = `.btn-close`** — `1em` ของ Bootstrap อ่านจาก font-size ที่สืบมา ในแผงนี้คือ `--fs-xs` จึงได้ 28px ไม่ใช่ 32 · ตั้ง `font-size: var(--fs-md)` + padding `--sp-2` ได้ 32 และยังขยายตามการตั้งค่า S/M/L ซึ่งเลข 16px ตายตัวทำไม่ได้ · **margin ลบเฉพาะแนวตั้ง** — ถ้าลบแนวนอนด้วย ปุ่มจะเลื่อนขวา 8px (centerX 1067 แทน 1059 ที่วัดไว้ก่อนแก้)

**ที่ยังไม่ได้ทำ** — `docs/design/components.php` ยังเดโมเมนู `.lo-history-*` ที่ H-ui ถอดไปแล้วตั้งแต่ 2026-09-19 (ของค้างเดิม ไม่ใช่ของรอบนี้) · ที่ < 576px บล็อกปุ่มพับลงใต้**ชื่อรายการ** ไม่ใช่ใต้คำอธิบาย เพราะจะย้ายใต้ sub-line ต้องทำ `<td>` เป็น flex ซึ่ง §7 ห้าม (พา `colspan` หายไปด้วย)
